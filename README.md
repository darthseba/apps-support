# Información para clientes de iOS — SebaLabs

Repositorio de páginas públicas de soporte y privacidad para clientes de iOS de las aplicaciones de SebaLabs.

Su finalidad es ofrecer información accesible desde enlaces de ayuda y desde las fichas correspondientes de las aplicaciones.

## Contenido

- `index.html`: portada del sitio de ayuda.
- `monitor-bebe/`: páginas de soporte y privacidad de Monitor de Bebé.
- `workout-timer/`: páginas informativas de Workout Timer.
- `README.md`: explicación del repositorio para su mantenimiento.

La portada revisada enlaza Monitor de Bebé. La existencia de una carpeta de otra app no implica que ya esté enlazada desde esa portada.

## Qué debe encontrar el cliente

- Explicación de la aplicación y sus funciones.
- Instrucciones de uso y ayuda ante problemas.
- Política de privacidad.
- Medio de contacto.

## Relación con las aplicaciones

El código de las aplicaciones se mantiene en sus propios repositorios:

- [Monitor de Bebé](https://github.com/darthseba/monitor-bebe).
- [Workout Timer](https://github.com/darthseba/workout-timer).

Este sitio contiene información para sus clientes de iOS; su contenido puede mencionar compatibilidad con otras plataformas cuando sea necesario para explicar el uso.

## Mantenimiento

Las páginas son archivos HTML estáticos. Para una actualización:

1. Modificar la página de la aplicación correspondiente.
2. Confirmar que las instrucciones coincidan con la versión distribuida.
3. Revisar enlaces, contacto y fecha de actualización.
4. Comprobar su lectura en pantalla de teléfono.
5. Revisar y aprobar el cambio antes de publicarlo.

La información de privacidad debe describir el comportamiento real de la aplicación. No incorporar datos de clientes, claves ni configuración privada.

## Alcance de esta propuesta

Se prepara documentación del repositorio y una descripción breve en español. Las páginas destinadas a clientes no se modificaron durante esta revisión.
